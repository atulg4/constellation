# Mission 011 - Reference Messenger

## Summary

Build a small reference messenger to validate the SDK, not as the product center of gravity.

## Acceptance Criteria

- [ ] Messenger uses only public SDK APIs.
- [ ] Offline store-forward message delivery works.
- [ ] Security limitations are visible.

## Required Tests

- End-to-end messaging tests.
- Wrong-recipient and tamper tests.

## Non-Goals

- Social network.
- Feed/recommendation system.
