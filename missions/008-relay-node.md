# Mission 008 - Relay Node

## Summary

Implement optional relay/community node behavior for opaque object storage, discovery, and forwarding.

## Acceptance Criteria

- [ ] Relay policies are explicit.
- [ ] Relays cannot read payload plaintext.
- [ ] Abuse controls are enforced.

## Required Tests

- Relay storage quota tests.
- Malicious relay behavior tests.
- Metadata logging review.

## Non-Goals

- Mandatory central relay.

## Dependencies

Missions 004 and 005.
