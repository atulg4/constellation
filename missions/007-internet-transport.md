# Mission 007 - Internet Transport

## Summary

Add Internet transport adapters such as QUIC/WebRTC while preserving end-to-end object security.

## Acceptance Criteria

- [ ] Internet transport is optional.
- [ ] NAT/signaling assumptions are explicit.
- [ ] Object security does not depend on link security.

## Required Tests

- QUIC/WebRTC adapter contract tests.
- NAT/signaling failure simulations.

## Non-Goals

- Mandatory cloud service.

## Dependencies

Mission 003.
