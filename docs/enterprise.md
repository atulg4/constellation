# Enterprise

Enterprise features must layer above or alongside the open core.

Future enterprise capabilities:

- organization-controlled identity bindings;
- managed private relays and gateways;
- private federation;
- policy-controlled replication;
- audit modes for enterprise namespaces;
- compliance retention policies;
- MDM/device management hooks;
- observability dashboards;
- hybrid cloud/on-prem deployments;
- SLA-backed infrastructure.

Enterprise controls must not create a mandatory global account system, certificate authority, relay network, or cloud dependency for the base protocol.
